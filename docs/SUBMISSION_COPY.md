# Submission copy

## Name

CutRoom

## One-line description

A human-agent storyboard studio where directors lock creative intent and browser agents safely expand, branch, and continuity-check the cut through WebMCP.

## Short description

CutRoom turns WebMCP into a collaboration contract for filmmakers. A director seeds a scene and locks the decisions that define it. Any compatible browser agent can then inspect the live board, propose structured shots, expand coverage, create alternate cuts, and audit continuity—without an embedded model, API key, or hidden state. Locked shots are enforced inside every write path; all actions are visible, attributable, reversible, and locally persisted.

## Judging case

### WebMCP leverage

Eight imperative WebMCP tools operate on the same live state as the human interface. They use strict schemas, cancellation, read/write annotations, shared validation, guardrail errors, and verification-rich results. The agent supplies intelligence; CutRoom supplies a safe action space.

### Execution

The submission is a complete responsive application, not a mocked concept. It includes editable storyboard shots, deterministic paper-cut artwork, human locks, safe branching, continuity checks, provenance, local persistence, accessible controls, a built-in judge demo, tests, and production deployment.

### Potential impact

Independent filmmakers and film students often need more coverage ideas but cannot afford to lose authorship or visual continuity. CutRoom makes agent assistance useful at the exact point where creative intent is fragile.

### Creativity and ambition

The core idea is not “generate a storyboard.” It is an agent-neutral creative cockpit with an explicit human-agent contract: seed → expand → lock → branch. The pattern can extend from storyboards to video edits, design boards, music arrangements, and other creative timelines.

> Inspect this storyboard. Expand it to six shots while preserving every director lock. Lock the strongest insert, create an alternate cut that reveals the stranger earlier, then check continuity and summarize every change.
